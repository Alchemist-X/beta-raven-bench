# 研究问题与领域地图

## 1. 评测到底测什么

目标是衡量 AI 对尚不确定的现实事件给出概率的能力，例如：

- 某国会不会在年底前降息；
- 某项法案会不会在截止日前通过；
- 某场比赛谁会获胜；
- 某产品会不会在指定窗口发布。

对二元事件，模型在锚点 `t` 给出：

```text
p_hat_t = f(F_t),  p_hat_t ∈ [0, 1]
```

结算后得到 `Y ∈ {0,1}`，再用 proper scoring rule 评价。Benchmark 的核心不是让模型“猜中”，而是让它在不完整信息下诚实、可校准地表达不确定性。

严格的 question object、信息集合、Agent 搜索轨迹、结算函数、Brier 聚合和人类对照定义见：[Forecasting 问题的形式化定义](../specification/01-forecasting-problem-definition.md)。

## 2. 为什么历史题很危险

直接让现代模型回答已经发生的事件，会同时混入两种能力：

1. 它是否记得结果；
2. 如果不知道结果，它是否能根据当时证据预测。

只有第二项是 forecasting。只要结果进入预训练、后训练或检索页面，分数就会高估预测能力。

## 3. 两条基本路线

### Live / prospective evaluation

模型预测尚未结算的事件。答案在作答时尚不存在，因此结果不可能已被记住。

优点：

- 参数和检索中的直接结果泄漏在构造上不存在；
- 与真实部署最接近；
- 可长期滚动更新，降低静态题库污染。

限制：

- 必须等待事件结算；
- 新模型不能立刻在旧时点复跑；
- 不同时期题目难度不同；
- 前沿模型差距很小时，需要大量独立事件才能分辨。

代表工作：ForecastBench、FutureX、Prophet Arena。

### Pastcast / retrospective evaluation

选择已经结束的事件，但重建历史锚点的信息环境，让模型只读当时已经存在的材料。

优点：

- 随时运行和复现；
- 可建立大样本；
- 可为同一事件设置多个锚点；
- 适合诊断和训练。

限制：

- 模型参数可能已经知道结果；
- 检索可能返回后验内容；
- 出题者可能无意使用结果信息；
- 容易复制预测市场或人群共识。

代表工作：Autocast、BTF-2、OracleProto、FutureSim。

Raven 暂将这一模式命名为 **TimeLock**，强调环境被锁定在过去，而不是让模型“假装忘记”现在。

## 4. 四条泄漏通道

| 通道 | 典型失败 | 为什么直觉防线不够 | 更强防线 |
|---|---|---|---|
| 参数 | 模型训练里见过结果 | 厂商自报 cutoff 可能不准确 | effective-cutoff probe、缓冲窗口、Live 对照 |
| 检索 | 搜索返回更新页面或事后报道 | `before:` 过滤依赖错误元数据和动态页面 | 当时真实抓取的冻结快照 |
| 选题 | 题面或“已结算”选择暴露答案 | 字符串去污发现不了语义捷径 | outcome-blind 出题、旧模型 shortcut 审计 |
| 基线 | 模型直接看到市场概率 | 模型只需轻微复制即可高分 | market-blind runtime，市场仅用于评分 |

结算过程必须使用事后信息，这本身不是泄漏；问题在于结算标签是否正确。结算错误会破坏 proper scoring 的含义，因此需要多信源、低置信丢题和错误率报告。

## 5. 样本量为什么重要

单题 Brier 噪声很大。检测两个模型很小的真实差距，需要的独立事件数近似随 `1 / effect_size²` 增长。文献给出的一个具体估算是：若目标差距约 0.01，可能需要约 1,400 条独立预测。

注意“独立”二字：

- 同一事件的多个锚点不是独立事件；
- 同一大选下的几十个相关问题也不是独立事件；
- 统计必须按 event 或共同潜变量分组。

这也是 Raven 以 TimeLock 获得样本量、再用 Live 做有效性验证的原因。

## 6. 领域目前的共识与争议

相对成熟：

- Brier、log score 等 proper scoring rule；
- calibration、resolution 与 Murphy decomposition；
- 结果结算后作为 SFT/RL 信号的基本方法。

仍未解决：

- 闭源前沿模型的真实参数知识边界；
- 大规模、可访问且可证明时点的冻结检索环境；
- 市场、人群与独立预测能力的分离；
- 多锚点更新质量的权威定义；
- 既透明又不容易被训练污染的长期 benchmark 治理。
